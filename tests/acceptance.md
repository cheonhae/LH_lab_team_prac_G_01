## 4. 경계 입력 (다른 조를 시험할 때 우리가 쓸 것 — 2개, 상급 조는 4개)

경계 입력은 표본과 따로, 아래 내용을 메모장에 붙여 `.csv`(UTF-8)로 저장해 기능 A에서 불러옵니다. 예상 동작은 `docs/team_plan.md` 1절의 **[가정]** 실패 동작·경계 조건에서 가져왔습니다.

| # | 경계 입력 | 예상되는 올바른 동작 |
|---|---|---|
| B1 | 빈 행·같은 서류 두 번·없는 신청유형 — `신청번호,신청유형,서류명,발급일` / `R-101,고령자,주민등록등본,2026-10-05` / (빈 행) / `R-101,고령자,주민등록등본,2026-10-05` / `R-101,고령자,소득확인서,2026-10-06` / `R-102,청년,주민등록등본,2026-10-07` | 빈 행은 건너뛰고, 같은 서류 두 번은 한 번으로 센다. 기능 A에 누락 1건(R-101 고령자 — 무주택확인서)이 보이고, R-102는 누락이 아니라 '확인 필요'에 "필수서류표에 없는 신청유형" 사유와 함께 보인다 |
| B2 | 발급일 경계·형식 오류 — `신청번호,신청유형,서류명,발급일` / `R-201,고령자,주민등록등본,2026-10-01` / `R-201,고령자,소득확인서,2026-09-30` / `R-201,고령자,무주택확인서,2026/10/10` | 기능 A에 누락 0건. 기능 B에 발급일 어긋남 1건(R-201 소득확인서 2026-09-30)이 보이고, 공고일 당일(2026-10-01) 발급은 어긋남이 아니다. 2026/10/10은 '확인 필요'에 "발급일 형식 오류" 사유와 함께 보이고 어긋남 숫자에 넣지 않는다 |
| B3 | 머리행이 다른 CSV — `번호,유형,서류,날짜` / `R-301,일반,주민등록등본,2026-10-05` | 안내에 `신청번호, 신청유형, 서류명, 발급일` 네 열 이름이 보이고 저장하지 않는다. 누락 목록과 시작 페이지 요약 숫자가 바뀌지 않는다 |

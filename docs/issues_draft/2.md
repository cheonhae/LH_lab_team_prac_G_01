# [기능] 누락 서류 대조 페이지

> 역할: ② 기능 A (B) · 리뷰 짝: ① (A) · 커밋 머리 `[팀-기능A]`

## 목적

- 제목 규칙: `[기능]` 누락 서류 대조 페이지
- 요구사항: `docs/team_plan.md` R1 — 신청 서류 CSV를 파일 선택으로 불러와 신청 유형별 필수서류표(가상)와 대조하고 누락 서류를 표시한다

## 완료 기준

- ☐ 성공: S1 — 기능 A 페이지에서 표본 CSV(신청 20건·서류 70행)를 불러오면 누락 4건이 신청번호·신청 유형·빠진 서류 이름과 함께 보이고, 이름·연락처 칸은 없으며, "담당 검토 후 확정"이 보인다
- ☐ 저장(화면으로 확인): 불러온 뒤 시작 페이지로 가면 요약에 누락 4가 보이고, 기능 A 페이지를 새로 고침해도 누락 목록이 그대로 보인다 (`docs/design.md` 2절 `docs`·`missing`·`checks` 모양)
- ☐ 실패할 때: 머리행이 다른 CSV를 불러오면 안내에 `신청번호, 신청유형, 서류명, 발급일` 네 열 이름이 보이고, 누락 목록과 시작 페이지 요약 숫자가 바뀌지 않는다
- ☐ 경계: `tests/acceptance.md` 4절 경계 입력(빈 행·같은 서류 두 번·필수서류표에 없는 신청유형)을 넣으면 그 표의 기대 숫자가 보인다 — 필수서류표에 없는 신청유형은 누락이 아니라 "확인 필요"에 사유와 함께 보인다
- ☐ `tests/acceptance.md`의 AC1·AC4·AC6 통과

# [기능] 시작 페이지 뼈대와 통합 (요약·백업·비우기)

> 역할: ① 통합·화면 (A) · 리뷰 짝: ② (B) · 커밋 머리 `[팀-통합]`

## 목적

- 제목 규칙: `[기능]` 시작 페이지 뼈대와 통합
- 요구사항: `docs/team_plan.md` R3 — 시작 페이지에서 메뉴, 요약(누락 n·발급일 어긋남 n), JSON 백업 내보내기·가져오기, 비우기
- 뼈대 PR: `tools/index.html`·`assets/common.js`(저장 함수 5개)·`assets/style.css`와 기능 페이지 2개로 가는 메뉴를 먼저 고정한다 (본문 `Refs #{이 이슈 번호}`)
- 통합 PR: ②·③ 병합 뒤 요약·백업·가져오기·비우기를 맞춘다 (본문 `Closes #{이 이슈 번호}`)

## 완료 기준

- ☐ 성공: S3 — 시작 페이지에서 백업 내보내기를 누르면 요약에 누락 4·발급일 어긋남 3과 "담당 검토 후 확정"이 보이고 JSON 백업 파일이 내려받아진다
- ☐ 성공: S4 — 비우기 뒤 S3의 백업을 가져오면 비우기 직후 요약 0, 가져온 뒤 시작·기능 A·B 페이지에 다시 누락 4·발급일 어긋남 3이 보인다
- ☐ 실패할 때: 백업 파일이 JSON이 아니거나 `docs/design.md` 2절 칸이 없으면 안내하고 기존 데이터를 그대로 둔다
- ☐ 경계: 저장된 데이터가 없으면 요약은 0으로 보인다
- ☐ `common.js`는 `docs/design.md` 3절 함수 5개만 담고, 키는 `teamG3_app` 하나만 쓴다
- ☐ `tests/acceptance.md`의 AC3·AC5·AC6 통과

## 검증 방법

- `python tests/run_acceptance.py` — AC5·F1~F4 실패 0건
- 브랜치 ZIP을 풀고 `tools/index.html` 더블클릭 → 표본으로 S3·S4 순서대로 확인(통합 PR)

## 담당 파일

- `tools/index.html`, `tools/assets/common.js`, `tools/assets/style.css`, `README.md`, `docs/demo_script.md` — 이 파일만 고칩니다

## 선행 이슈

- 뼈대: 없음
- 통합: ② 기능 A, ③ 기능 B가 병합된 뒤

## PR 연결

- 뼈대 PR은 본문 첫 줄에 `Refs #{이 이슈 번호}`, 통합 PR은 `Closes #{이 이슈 번호}`를 씁니다.
